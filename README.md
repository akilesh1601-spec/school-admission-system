# AdmitSchool — School Admission System

A front-end demonstration project built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portal sections
- `style.css` — responsive purple-and-white styling
- `script.js` — forms, applicant records, status updates, document records, exam scores, merit ranking, fee records, and CSV export

## Run locally
1. Download and extract the project ZIP.
2. Open the `SCHOOL_ADMISSION_SYSTEM` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Notes / limitations
- This is a front-end demo; it does not use a server or database.
- Records are saved in the current browser using `localStorage`.
- Document upload is simulated: only the filename is recorded; the file itself is not uploaded to a server.
- Login/authentication and fee payments are not real services.
- Data is local to the browser/device and is not shared between users.
